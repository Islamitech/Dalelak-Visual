# Dalelak Visual Identity Studio • ستوديو الهوية البصرية والتصميم والكتالوجات (المرحلة 2)

منظومة التصميم الذكية للأنشطة والخدمات الميدانية المسجلة في **دليلك**.

## المميزات الأساسية:
1. **تحويل اللافتات الميدانية إلى شعارات فيكتور (Signboard-to-Vector AI Logo):** تحليل صور لافتات المحلات الحقيقية وتوليد شعارات فيكتور قابلة للتكبير والتعديل.
2. **صانع براويز وقوالب السوشيال ميديا (Social Media Frames):** إطارات عصرية بمقاسات (1080x1080 مربع و 1080x1920 ريلز) تدمج صور منتجات المحل بضغطة زر مع شارات الخصومات وشريط التواصل.
3. **صانع قوائم الأسعار والمنيو (Menu & Catalog Maker):** صانع كتالوجات ومنيو ذكي مع اقتراح بنود تلقائياً حسب فئة النشاط وتصدير PDF عالي الجودة للطباعة.
4. **صانع بوستات العروض والتخفيضات (Promo & Discount Banners):** تصاميم إعلانية جذابة مع صياغة عروض باللهجة المصرية لزيادة المبيعات.
5. **معمارية السيرفرات المزدوجة:** ربط مباشر بسيرفر دليلك الأساسي لجلب الأنشطة وصورها، وحفظ مسودات الأصول في سيرفر المنظومة، مع زر للترقية والاعتماد النهائي.
6. **مظهر نهاري ناصع ومريح (Light Mode Only):** تصميم مريح للعين واحترافي للطباعة والتصميم.

## التشغيل:
```bash
npm install
npm run dev
```
يعمل الخادم تلقائياً على المنفذ: `http://localhost:3002`
